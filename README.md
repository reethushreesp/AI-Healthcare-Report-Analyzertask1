# AI Healthcare Report Analyzer

## Project Overview
AI Healthcare Report Analyzer is a web-based application developed using Python and Flask. It helps users upload healthcare reports and analyze the report content using Google's Gemini AI.

The application provides AI-generated insights based on the uploaded report.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Google Gemini AI API
- PyPDF
- Python Libraries

## Features
- Upload healthcare reports in PDF and TXT formats.
- Extract text from uploaded reports.
- Analyze report content using Google Gemini AI.
- Generate AI-based summaries and insights.
- Simple and user-friendly web interface.

## Installation and Setup

1. Clone the repository:
```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Navigate to the project folder:
```bash
cd AI-Healthcare-Report-Analyzer
```

3. Install the required dependencies:
```bash
pip install -r requirements.txt
```

4. Configure your Google Gemini API key using an environment variable. Do not share your API key publicly.

5. Run the application:
```bash
python app.py
```

6. Open your browser and visit:
```text
http://127.0.0.1:5000/
```
